# Offre de démonstration — critères du profil recherché

Critères repris de la section « Profil recherché » de l'offre Atypix, à coller dans l'outil (un critère par ligne). Les quatre derniers sont des atouts, pas des exigences.

1. Au moins un an de développement web en JavaScript ou TypeScript côté serveur (Node.js)
2. Pratique de React
3. Bases de SQL et de PostgreSQL : requêtes, jointures, migrations
4. Usage quotidien d'un assistant de code IA, avec relecture
5. Au moins une intégration d'API de modèle de langage (Claude, OpenAI ou autre)
6. Pratique de Git et de la ligne de commande Linux
7. Anglais technique lu
8. Expérience de Next.js (atout)
9. Notions de développement mobile : React Native, Expo ou PWA (atout)
10. Outil d'automatisation : n8n, Make ou Zapier (atout)
11. Tests automatisés avec Vitest ou Playwright (atout)
